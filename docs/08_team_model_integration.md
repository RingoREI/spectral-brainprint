## 输入名称与比较对象

- **S171**：对数协方差空间统计。
- **P108**：频带功率，包含周期和非周期背景的共同贡献，不能称为纯周期成分。
- **A36**：18 个通道的 offset 和 exponent；独立矩阵需核对实际列定义、单位、输入视图和拟合约定。
- 历史团队输入的 `periodic` 为 **P108＋S171＝279 维**。关闭整个历史分支会同时删除空间信息，不能直接解释为周期特征消融。
- 历史 MLP20 的 705 维为 **279＋36＋296＋47＋47**，还包含全局/伪迹统计与事件均值、标准差。它与拟议的 315 维 S+P+A 模型有不同输入范围。

原始 EEG 已包含周期与非周期信息。“EEG-only CNN”表示不额外提供显式谱特征；拟议实验检验特征表示与建模方式的增益。

## 下一轮消融大纲：待讨论

### 先导：同一小型 MLP 的特征对照

| 组别 | 输入 | 有效特征维数 |
|---|---|---:|
| 空间基线 | S | 171 |
| 加功率 | S+P | 279 |
| 加非周期 | S+A | 207 |
| 两者合用 | S+P+A | 315 |

这一步连接现有 LDA 基线，检验功率与 A36 的收益在非线性分类器中是否保持。主要关注 S+P+A 相对 S+P 的 A36 增益，也报告其他配对差值。具体网络、输入槽位和训练预算尚待确认。

### 主问题：显式谱特征相对 EEG-only 深度模型的增益

| 组别 | 原始 EEG CNN | P108 | A36 |
|---|:---:|:---:|:---:|
| EEG-only 基线 | ✓ |  |  |
| 加功率 | ✓ | ✓ |  |
| 加非周期 | ✓ |  | ✓ |
| 两者合用 | ✓ | ✓ | ✓ |

比较加 P、加 A、两者合用及其条件增益，检查互补或冗余。该四组融合实验尚未实现。实验规则的大纲是：

- 同一比较使用相同记录、划分、输入视图与预处理；各组从头训练。
- 保持可比较的主干、融合头与调参预算，记录参数量及成本；关闭分支时明确屏蔽编码输出，避免仅清零输入后仍有偏置输出。
- 训练部分内部的开发集用于早停与选模；已有历史折继续标为开发证据，最终独立评估另行安排。
- 使用配对随机种子，报告主指标 balanced accuracy，以及 accuracy、macro-F1、逐身份召回和错误变化；重复种子不计作新增独立记录。
- 先验收 A36，再从 EC 小规模流程验证逐步扩展到更多折、种子和其他任务。超参数、具体运行矩阵和验收阈值在讨论后确定。

开放集拒识、伪迹块的贡献、扰动和图连接各有独立问题，留在后续阶段。当前大纲先回答闭集识别中的显式特征增益。更完整的原则见[实验协议](06_experiments.md)。

## 旧 MLP20 推理参考

以下命令仅用于取得配套资产后的旧模型复现，不是新消融训练入口。安装 `python -m pip install -e ".[deep]"` 后，使用真实交接文件替换本地占位路径；`--template` 可选。

```powershell
python -m spectral_brainprint predict-mlp20 `
  --features local/test_vectors_raw.npz `
  --checkpoint local/seed-20261102/model.pt local/seed-20261103/model.pt local/seed-20261104/model.pt `
  --calibration local/ensemble_calibration.json `
  --template local/test_template.csv `
  --trust-legacy-checkpoint `
  --output artifacts/mlp20/predictions.csv
```

NPZ 的 `x` 为原始 705 维向量，需有唯一记录标识和 `sample`；融合 HDF5 的 A 输入为 `[N,18,2]`，每通道 `[offset,exponent]`，有效性掩码为 `[N,18]`。每个成员使用自己的训练折中位数/IQR，按固定种子顺序平均 raw logits，再与冻结阈值比较。

11 月 5 日的约 3.89% 已知尾部分位与 11 月 6 日 q05 配置不同，不能混用权重与校准文件；多噪声工作流也有自己的校准结构。`--trust-legacy-checkpoint` 只用于团队可信来源的旧档案。拒绝数量可用于行为检查，识别与未知拒识性能仍需有标签的对应评估集。

源码来源对应：`models/mlp.py` 与 `io/team_vectors.py` 对应 `brainprint_mlp20_candidate_20261105` 的训练/部署适配；`models/fusion.py` 对应 `brainprint_team_training_20261103/brainprint/model.py`；`models/neural_baselines.py` 对应 `brainprint_groupcal_multimodel_20261105/architectures.py`。来源交接范围见[资产审计](04_asset_audit.md)。
