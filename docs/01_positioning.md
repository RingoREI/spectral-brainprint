# 项目定位与证据边界

版本：2026-11-12。依据：本次用户计划与本地已检查代码、配置、索引及历史报告；本文不作外部文献新颖性判断。

## 1. 一句话定位

Spectral Brainprint 是面向短时多通道EEG身份识别的可复现研究框架，以可解释的谱参数和空间统计为起点，检验非周期信息的独立贡献，并在统一验证协议下评估轻量深度表示与融合的收益。

中文描述保留“融合周期、非周期与空间统计特征的可解释EEG神经指纹识别框架”。“可解释”首先指特征定义、单位、计算过程及分块贡献可追溯，不能直接推出神经生理因果机制。静态谱参数不代表完整神经动力学；只有加入时间变化、稳定性等证据后，再考虑“神经动力学”表述。

## 2. 研究问题与判定

| 问题 | 比较 | 支持该结论需要什么 |
|---|---|---|
| 非周期是否提供额外身份信息 | P+S 与 P+S+A18/A36，固定记录与分类器 | 预先确定协议的配对增益、区间和失败案例；排除质量/任务/会话字段泄漏 |
| 增益是否具有可迁移性 | 任务内、跨任务、可靠记录组/Run、独立有标签会话 | 分别报告；一种协议不能替代另一种；缺元数据时结论降级 |
| 非线性是否必要 | 相同特征、相同划分的LDA与小MLP | 调参预算、随机种子、参数量及训练时间透明 |
| 双分支是否值得 | 原始EEG编码器、谱特征支路、双分支融合 | 对照分支消融；统一数据与预算；报告延迟、容量、缺失特征处理 |
| 抗扰和拒识能否兼顾 | 固定模型/阈值下的干净与扰动配对 | 区分误分类、正确但被拒绝、未知被接纳；阈值在独立开发集确定 |

P=功率108，S=对数协方差171；A18暂拟18通道exponent，A36暂拟offset+exponent，最终以非周期分支实际模式/列字典为准。含knee的模型需独立版本，不强行套入18/36维。

## 3. 转化对象与交付层级

第一受众是课题组和合作同学：能够用同一记录集合比较已有算法。第二受众是外部研究者：无需私人数据即可运行合成示例，并根据数据适配器复用框架。第三阶段才考虑身份验证原型的使用者，需要注册流程、独立数据、误接受/误拒绝评估、模型更新及时延要求。

近期交付定位为**研究软件与实验资产**：可安装包、CLI、版本化配置、稳定接口、记录级预测、可追溯报告。论文、开源和演示原型可共享同一证据链，但分别验收。尚不承诺临床用途、生产安全认证、真实攻击防护或可商业化性能。

## 4. 当前可说与不可说

- 可说：已存在功率、空间及盲谱特征和固定LDA的同会话探索材料；本次迁移验证结果单独记录。
- 可说：在历史相同开发划分上，空间与功率组合优于功率单用；该结论仍有选择偏倚和元数据缺失限制。
- 待证明：非周期独立增益、深度融合优势、独立会话稳定性、拒识性能和抗真实攻击能力。
- 尚未确认：MLP的确切输入、模型、权重、类映射、阈值与成绩；当前文件未找到不代表团队没有。

功率108不是背景扣除后的“纯周期”量，空间171也不是纯周期或因果连接。历史峰拟合探索效果一般且已暂缓；本轮整理不会自动重启它。

## 5. 研究贡献候选

优先形成“增量信息的可信评估 + 可复现工程”的贡献，而不是提前认定某个融合模型必然创新。若A无增益，仍应保留负结果，分析其与功率/空间冗余、拟合稳定性及混杂。若MLP无稳定收益，优先保留简单模型；是否保留融合，以可靠验证与复杂度权衡决定。
